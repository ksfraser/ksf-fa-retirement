# FR-003-004 FACapture: FA Capture & Display of Retirement Planning Plan

**Related:** BR-003 Retirement Planning, FR-003-001..003

## Description
The FrontAccounting module lets an advisor open a client's Retirement Planning plan, run the `Ksfraser\Retirement` engines, and display results inline.

## Primary actor
Advisor.

## Main flow
1. Advisor opens Retirement Planning Planning from the client menu. 2. System loads plan and runs engines. 3. Results persist against the client record.

## Postconditions
Retirement Planning plan results visible and stored for the client.
